## 🎯 Elevator Pitch
I built a highly customized, next-generation personal developer portfolio from scratch using **HTML, CSS, and Vanilla JavaScript**—without relying on heavy frameworks.  

✨ Features include:  
- Glassmorphism UI with interactive 3D elements  
- Dynamic particle background  
- AI Voice-Activated Navigation using the Web Speech API  
- Asynchronous contact form powered by Web3Forms API  

---

## 🛠️ Technical Breakdown

### 1. Advanced AI Voice Navigation
- Implemented browser-native **SpeechRecognition API**.  
- Custom JavaScript logic parses transcripts and maps keywords to navigation functions.  
- Commands like *“Please go to contact”* trigger instant navigation.  
- Added a **3-second cooldown algorithm** to prevent duplicate command execution.  

---

### 2. Modern UI & Interactive Visuals
- **Glassmorphism Design:** Frosted glass cards using `backdrop-filter: blur`.  
- **Vanilla Tilt 3D:** Hover-based tilt physics for project cards.  
- **Particles.js:** Interactive particle background reacting to cursor movement.  
- **Custom Cursor:** Dual-element trailing cursor built with JavaScript event listeners.  

---

### 3. API Integration & Asynchronous State
- **Contact Form Backend:** Integrated **Web3Forms API**.  
- **AJAX Handling:** Used `fetch()` with `e.preventDefault()` for async form submission.  
- **Custom Toast Notifications:** CSS-based toast alerts for success feedback and auto-clearing form fields.  

---

### 4. Core Functionality & Accessibility
- **Dark/Light Mode:** Theme toggler with CSS variables and `localStorage` persistence.  
- **Responsive Design:** Flexbox + Media Queries for mobile optimization.  
- **Hamburger Menu:** JavaScript-driven toggle for mobile navigation.
